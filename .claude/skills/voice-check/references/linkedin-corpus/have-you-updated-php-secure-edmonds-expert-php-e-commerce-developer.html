Have You Updated PHP? Are you Secure?

Created on 2019-09-17 14:40

Published on 2019-09-17 14:59

Recently some serious vulnerabilities were discovered in PHP

PHP is a programming language that powers a huge percentage of the internet and is used by websites running platforms like Magento, Wordpress, OpenCart and a long list of other platforms. It is the language that Edmonds Commerce specialise in.

We've been talking to all of our clients about the security issues and ensuring that they are updated promptly. For some clients the upgrade was very simple as they are already running modern platforms like Magento 2 and have been keeping them up to date, with our help of course.

Other clients were less simple due to the fact that they are running on older legacy platforms like Magento 1 - especially if that platform has not been kept totally up to date including the underlying PHP software.

There are a surprisingly large number of people who are still running very old PHP versions (less than 7.1) and for these people, the task of upgrading is much more involved - however the benefit that upgrading brings has never been greater. Not only will upgrading to the latest PHP version ensure you are secure, but it will also bring huge performance improvements that can make a very real difference to how quickly your website loads.

Hopefully you are already aware of the recent vulnerabilities and have already taken the required action to get things updated. If you haven't, I really encourage you to take action as a matter of high priority. If that means you have to finally make the decision to properly update your code base and server software then so be it, the benefits are clearly there but the security concerns are now also very real.

Given access to a code base, we can run tools that allow us to quickly quantify the amount of work that will be required to get it running on the latest PHP versions.
