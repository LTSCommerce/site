Magento 2 is Stable

Magento 2 has been out for quite some time now. It was in development for a long time and eventually 2.0 was released on the 17th of November 2015.

Now we are up to version 2.2.2, released on the 12th of December 2017. The latest version not only includes lots of nice features but has now had plenty of time to iron out a huge number of wrinkles with the system.

I think most people would now agree that Magento 2 is now stable.

Magento 2 Fully Supports PHP 7

PHP, the language Magento is written in, has enjoyed frequent and significant upgrades. The current version of PHP is 7.2.1 and it is widely accepted to be significantly faster than PHP 5.6 as required by Magento 1.

In fact, PHP 5.6 will be completely out of security updates by the end of 2018.

Note - it is possible to patch a Magento 1 site to support and run with PHP 7, however you do have to accept that it is not designed for it and also extensions are more than likely not testing with it. Certain extension vendors have been know to refuse to support issues when running PHP versions greater than 5.6

Magento 2 Natively Supports Varnish

Varnish Cache is a web application accelerator also known as a caching HTTP reverse proxy.

By using Varnish, it is possible to provide really huge speed improvements when serving cached pages and assets. On a proper configuration we can be talking single digit milliseconds to serve a page.

Magento 2 natively supports Varnish which means that you can enjoy this kind of speed as long as your server and Magento installation are correctly configured.

I will admit that some hosting companies are dragging their feet a bit when it comes to properly supporting Varnish and so you will need to make sure that your development agency are able to bridge the gap and handle the Varnish side of things for you.

Magento 2 is Being Actively Developed

Currently Magento 2 is enjoying a new release every month. Furthermore, compared to Magento 1, it is vastly simpler to upgrade a Magento 2 site. It is entirely feasible that you will be able to keep your Magento 2 site at or close to the latest stable release at all times and without onerous amounts of developer time required.

Whilst Magento 1 is still not officially end of life, there are various things that indicate that it might not be November 2018, but it probably won't be too much more beyond that. It is safe to say that by 2020, Magento 1 will be dead.

Now you might say that is ages away, and you'd be right, however - planning, resourcing and executing a proper migration to Magento 2 is not something that can be done in a day. High quality Magento development agencies are busy.

If you want to get off the Magento 1 train before it pulls into the sidings then I'd say that 2018 is the year to really get that process underway.
