A bit of Back Story First:

One the biggest problems facing developers and store owners of Magento and other platforms is that it is hard to ensure the system is bug free.Often there is a tacit acceptance that software is doomed to always be buggy and its a question of staying as on top of that as possible.

Whilst this is true, its not the the full story.

The real story is that its an inhuman task to test every facet of a system every single time that a change is made. If you introduce code from multiple third parties then the situation is infinitely more complex because you are running code from a third party that might never have been tested in exactly your code base and configuration.

The answer is to do what any developer does when faced with a huge manual task - automate it.

Automated Testing

Automated testing comes in two main flavours - unit testing and integration testing. Unit tests are designed to test snippets of code in isolation to ensure that given certain inputs they produce the correct outputs. Integration tests are for testing the system as a whole. In an ecommerce sense, this means firing up a browser and automatically running through a suite of user stories to ensure that the site is working correctly.

Those in the know realise that Magento 1.x is basically untestable. With effort it is possible to get quite a long way towards having it well covered by automated tests but the holy grail of having it fully tested is probably just too big a target. Now that Magento 2 is on the horizon then is this is unlikely to ever happen as developers are now starting to focus their attention on that platform instead. It's worth pointing out that one of the key features of Magento 2 is that testing has become a first class part of the platform.

However even with their best efforts, the fact that Magento 2 has taken so long to come out, it is already behind the cutting edge on quite a few aspects, especially to do with approaches to testing.

Sylius

The platform I am really keeping an eye on is one called Sylius. It is based on the highly respected and Enterprise ready PHP framework Symfony.

It is currently under active development and is being built using some cutting edge techniques and something called Test Driven Development that ensures that testing and testability are built in from the ground up.

The outcome is a system that is entirely testable - automatically. Make a change, run the full suite of tests and then deploy knowing that you have tested the whole system incredibly thoroughly so you have a very high level of confidence that everything is working fine.

I sincerely believe that the chase for features epitomised by the stellar success of Magento is going to be eclipsed by the chase for enterprise level stability that can only be provided by a platform such as Sylius.
