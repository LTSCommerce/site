The Importance of Code Control and Deployment

Created on 2014-02-26 09:56

Published on 2014-02-26 10:07

One of our most popular services that we are providing to our clients at the moment is setting up code control.

We take their current e-commerce web site code and set it up in version control so that there is a clear audit trail of all changes made to the site.

Further to this we also then set up development and staging versions of the site which are private and are places where code that is in development or in final testing before being deployed live can go.

Finally we set up some scripted processes to manage the movement of code changes from development to staging and finally to deployment on the live web site.

Disaster Recovery

This formalised structure backed up by proper version control provides all kinds of important benefits. First of all, in case of something being deployed that causes critical issues it is trivial to revert the changes back to a previous state. This alone is worth setting it up.

Co Working

By using version control it is much easier for multiple parties such as ourselves and your in house technical resources to both be working on your site without any risk of clashing. If you have external web design, copy writers, SEO or others who need to contribute code changes then this can all be handled in a sane way by using version control.

Deployment

Using a version control system to manage code deployments are fully under control and can easily be tested in staging and then an exact replica be deployed with full confidence that everything will work properly.

Conclusion
