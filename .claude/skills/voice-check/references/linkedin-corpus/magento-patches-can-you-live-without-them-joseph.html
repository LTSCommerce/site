Patching Day!

Today is a familiar day to many Magento store owners and especially Magento developers. It's patching day!

Magento have released the latest suite of patches and upgrades to address a large number of security issues that have been found and affecting all versions of Magento. You could be forgiven for thinking that having a large number of security issues that need patching is a bad thing. In reality, any sufficiently complex system is almost certain to have a number of security issues that have not yet been detected. What is great about Magento is that the issues are being found and fixed meaning that as long as you keep up to date with patches then you can be quite confident that your site is secure.

For Magento 1 store owners, this is the aspect of the Magento ecosystem that you will lose out on if you do not upgrade to Magento 2 before July 2020.

From the developers point of view, we're seeing that the Magento 1 approach of applying patches is really showing it's age in comparison to the Magento 2 approach of using composer to update all the code with some simple commands. It is fair to say that keeping a Magento 2 store up to date and secure is a lot easier than for a Magento 1 store. It makes sense, Magento 2 is using much more modern practices and is not hindered by the now outdated practices that were adopted when Magento 1 was created.
